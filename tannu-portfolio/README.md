# Tannu Ranga — The Living Fieldbook

**An interactive developer portfolio where curiosity, creativity, and software engineering meet.**

The Living Fieldbook is my personal portfolio, designed as an interactive digital journal rather than a conventional developer portfolio. It documents my development journey through real projects, technical exploration, achievements, and community experiences.

Built with **React, TypeScript, Vite, and Motion**, the website combines editorial design, colorful interfaces, and purposeful animations while prioritizing responsiveness, accessibility, and performance.

## Getting Started

### Prerequisites

Install a compatible version of Node.js and npm.

### Clone the repository

```bash
git clone https://github.com/tannuranga25-lab/tannu-portfolio.git
cd tannu-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Create a production build

```bash
npm run build
```

The production-ready static files are generated in the `dist/` directory.

## Deployment

This portfolio is designed for deployment on Vercel.

**Configuration:**

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

Connect the GitHub repository to Vercel to enable automatic deployments from future pushes.
